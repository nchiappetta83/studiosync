# StudioSync 1.2.0

StudioSync 1.2.0 is a broad desktop-polish and reliability release for both StudioSync Dashboard and StudioSync MyTasks.

## Highlights

- Introduces a shared visual interaction system across both apps, including consistent buttons, menus, dialogs, inputs, focus states, notifications, and destructive actions.
- Adds a divider chevron for opening and collapsing the MyTasks detail pane in staff and partner workflows.
- Adds visible sync-failure health, explicit retry controls, and exponential backoff for damaged or partially written shared-drive events.
- Adds consistent pending, success, warning, validation, and error feedback throughout MyTasks.
- Adds Undo after task completion and protects unsaved Partner project edits during navigation or background refreshes.
- Improves keyboard access, modal focus trapping and restoration, tab semantics, and interactive card controls.
- Uses single-instance application behavior to prevent duplicate background process groups.
- Updates the Electron, electron-builder, SQLite, and UUID runtime dependencies used by both apps.

## Dashboard improvements

- Refines project and task creation, staff management, priorities, menus, rollover review, and runtime status presentation.
- Improves startup and shared-drive connection handling while preserving the local cached workspace.
- Aligns notifications and confirmation dialogs with MyTasks.

## MyTasks improvements

- Adds collapsible task and project details without requiring a Preferences change.
- Improves Partner project management, staff assignment visibility, project folder links, Project Notes, task ordering, and priority presentation.
- Adds a standalone Project Notes window and protects in-progress project edits.
- Improves sync recovery and makes failures visible from the main interface and Preferences.

## Downloads

- `StudioSync Setup 1.2.0.exe` installs the main Dashboard application.
- `StudioSync MyTasks Setup 1.2.0.exe` installs the companion application.
- The `win-unpacked` zip files provide portable extracted builds for testing and managed deployment.

The Windows installers are currently unsigned, so Windows SmartScreen may display an unknown-publisher warning.
