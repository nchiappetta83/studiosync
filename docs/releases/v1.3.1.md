# StudioSync 1.3.1

StudioSync 1.3.1 introduces shared Work Cards and Project Leads, and hardens sync recovery between StudioSync Dashboard and StudioSync MyTasks.

## Highlights

- Adds **Work Cards**: shared, project-level cards with a type, assignees, start and end dates, planned time, and a Start / Pause / Complete workflow. Partners create and edit cards; assignees run them from MyTasks.
- Each person can mark one assigned card as their current focus.
- Work Cards are shown on the MyTasks Team Calendar. Which types appear there is set per type in Dashboard Settings.
- Unfinished cards carry into the new week at the weekly rollover; completed cards stay in the week they were finished.
- Project leads are notified when another person completes a card on their project.
- Adds **Project Lead** on scheduled assignments. A lead applies to every assignment on the project and must be a person marked **Senior Staff**.

## Dashboard improvements

- New **Work Card Types** section in Settings to add, rename, recolour, reorder and delete types and to choose which show on the Team Calendar.
- New **Senior Staff / Project Lead** option when adding or editing staff. The option that lets people add projects to their own MyTasks list is now labelled **Can Add Projects In MyTasks**.
- A compact, read-only Work Card list under a scheduled project, so Monday scheduling stays as fast as before.
- Closing Dashboard with unpublished weekly changes offers **Close & Unlock MyTasks**, which releases MyTasks without publishing.
- The Dashboard no longer starts the weekly rollover when the app opens; it begins only when a scheduling administrator enters Dashboard. The shared scheduling lock is taken when a rollover starts and released when its changes are published.
- Dashboard publishes a recovery snapshot of the shared data, and the manual sync action republishes it.

## MyTasks improvements

- New Staff Overview assignment counts, which include completed assignments for active staff.
- Partners can edit the office daily and weekly capacity from MyTasks. It is stored in the shared folder.
- A new MyTasks install, or one with no local users, can restore users and shared data from the Dashboard snapshot. If that is not possible, the connection screen says why.
- Reconnecting to the same shared folder keeps private tasks and any queued local changes.
- The staff window opens at 775 px wide so the project list and Work Cards panel stay readable.

## Reliability and security

- Sign-in uses the StudioSync profile you select instead of the Windows account.
- Signed events are rejected when the author does not match the identity the device was enrolled for.
- A weekly review that its Dashboard never finishes or closes now expires after 12 hours instead of locking MyTasks and blocking the rollover.
- Deleted Work Card Types stay deleted.
- Synced task, work-card, project and user events no longer fail repeatedly when a project lead has lost Senior Staff status.
- Synced avatar colours are stored as received, so both apps show the same badge colour. New people are given distinct colours.
- Configuration and capacity files are written atomically, and an unreadable configuration file falls back to safe defaults.
- Database upgrades are applied automatically when each app starts.

## Build and release

- The release workflow runs both apps' smoke tests before building the installers.
- `npm test` runs the smoke tests on Electron's bundled runtime rather than the system Node, because `better-sqlite3` requires a newer Node than the workflow's Node 20.

## Downloads

- `StudioSync Setup 1.3.1.exe` installs the main Dashboard application.
- `StudioSync MyTasks Setup 1.3.1.exe` installs the companion application.
- The `win-unpacked` zip files provide portable extracted builds for testing and managed deployment.

The Windows installers are currently unsigned, so Windows SmartScreen may display an unknown-publisher warning.

Update the Dashboard and MyTasks together. Both are version 1.3.1 and share the new Work Card and Project Lead data.
